## 🚀 Quick Start Guide

### Static Webpages & Vanilla JS (Assignments 1–4)
Open any assignment folder and launch `index.html` directly in any web browser, or serve it using VS Code Live Server or python http server:
```bash
python -m http.server 8000
```

### React Applications (Assignments 6–7)
```bash
cd assignment-06-react-student-info
npm install
npm run dev
```

### Node.js REST APIs (Assignments 8–9)
```bash
cd assignment-08-student-rest-api
npm install
npm run dev
```
